# 30-Day Software Engineering, Data, AI & Automation Journey

A 30-day build-in-public learning journey focused on:

- Software Engineering
- Python
- Data Analysis
- Data Science
- AI
- Automation
- n8n
- Business Analysis

## Goal

Build practical skills by learning concepts, building real-world projects,
debugging problems, and documenting the journey publicly.
